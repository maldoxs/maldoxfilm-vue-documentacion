### Descubrimiento: la API privada de RD

Se investigó la API privada que RD usa internamente para su streaming. Hallazgos clave:

1. **`/d/{id}`** → REST API que devuelve `files` del torrent (nombre, tamaño, path). No streaming.
2. **`/t/{mediaId}/{combinedHash}/...`** → CDN endpoint que SIRVE los segmentos multimedia. Es la que realmente importa.
3. **`full.mpd?t={seconds}`** → genera DASH con segmentos empezando **en cualquier posición**. **Far-seek universal.**
4. **`full.mp4`** → progressive MP4 con HTTP Range → seek perfecto (sin depender de Shaka).
5. **`ping/{mediaId}/play`** → activa el stream (necesario antes de pedir segmentos).
6. **`ping/{mediaId}/{seconds}`** → dice a RD que genere segmentos a partir de esa posición.
7. **`/rest/1.0/streaming/mediaInfos/{mediaId}`** → endpoint privado que da: CDN, combinedHash, suffix, audio tracks (idiomas), resolution.

### Cómo se obtiene `mediaId`

- URL de streaming: `https://real-debrid.com/streaming-{rdId}?auth_token={token}`
- El HTML contiene: `setMediaId("{mediaId}")` → se extrae con regex.
- `mediaId` es normalmente el mismo `rdId` (pero no siempre).

### Verificaciones

- `ping/{mediaId}/play` → `200 OK`.
- `full.mpd?t=120` → devuelve MPD válido (DASH) con `availabilityStartTime` ajustado y segmentos desde segundo 120.
- `full.mp4` → progressive download, seek por Range funciona.
- `mediaInfos` da `{"cdn":"n6.real-debrid.com","suffix":"d/66UKOAEBEUWNG","audio":[{"id":"A1","lang":"eng"},{"id":"A2","lang":"spa"}]}`.
- El CDN del MPD puede diferir del `mediaInfos.cdn` → el navegador sigue el `<BaseURL>` del MPD.

### Flujo de reproducción

1. `bootstrap.ts` → obtiene `rdMediaId` vía boot stage
2. `rdMediaId` propagado a `usePlayer` y `streamSelector`
3. `scoreStream` da +20 si hay `mediaId` → elige pipeline `/t/`
4. `usePlayer` llama `useTpipeline` que:
   - Hace `ping/{mediaId}/play`
   - Obtiene `mediaInfos` (CDN, audio tracks)
   - Construye URL MPD: `{cdn}.real-debrid.com/t/{mediaId}/{combinedHash}/full.mpd`
   - Shaka Player reproduce el MPD
   - Seek: cambia `?t={seconds}` y recarga Shaka
5. Si falla → fallback a transcode DASH legacy + Direct Play

### Hallazgos técnicos del testing intensivo

|---|---|
| `shakaPlayer.load("?t=X")` pone `currentTime=0` | Offset `_mpdOffset`: display = offset + currentTime |
