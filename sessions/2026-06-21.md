## Lo hecho

### Pipeline /t/ integrado al proyecto (portado de PRUEBAS/)
El pipeline `/t/` descubierto y validado en la demo (`~/Desktop/PRUEBAS/`) fue portado
al proyecto principal `maldoxfilm-vue`. El pipeline usa la CDN privada de RD
(`full.mpd?t={seconds}`) para generar DASH en cualquier posición → far-seek universal.

**Archivos nuevos:**
- `netlify/functions/rd-tpipeline.js` — Netlify Function server-side (resolve/seek/mpd).
  Token RD nunca sale al navegador. Scrapea `streaming-{rdId}` → `mediaId`, llama
  `mediaInfos` (CDN, hash, audio tracks), hace `ping/play`, y construye URLs de MPD.
- `src/services/rd-t-pipeline.ts` — Cliente del pipeline: `resolveTpipeline`, `pingSeek`,
  `buildMpdUrl`, `waitForSegmentAt`, `pickBestAudio` (latino > español > inglés).

**Archivos modificados:**
- `src/composables/usePlayer.ts` — Nuevo camino transparente `tryTpipeline()` insertado
  DESPUÉS del Direct Play y ANTES del transcode legacy. Si `/t/` falla → cae al legacy
  sin corte. Incluye `tpipelineSeekTo` con debounce 300ms + mutex `_tReloading`.
- `src/composables/useNetflixControls.ts` — Overrides opcionales: `timeOverride`
  (offset + currentTime), `durationOverride` (duración del resolve), `seekOverride`
  (llama tpipelineSeekTo). Aplicados en `tick`, `skip`, `onSeekBarClick`.
- `src/components/player/VideoPlayer.vue` — Freeze-frame (canvas drawImage) + spinner
  azul durante seek. Panel settings se cierra al auto-hide de controles.
- `src/components/player/PlayerSettingsPanel.vue` — Fix `v-else` → `v-if="mode === 'speed'"`
  (el panel de velocidad se superponía al de audio/subtítulos).

### Flujo de reproducción resultante
```
Scoring elige [RD+] (sin cambios) → rdId
  → Direct Play? (sin cambios)
    → Pipeline /t/ (NUEVO: mediaId → ping → MPD?t= → Shaka)
      ✅ far-seek + AAC
      ❌ fallback transparente ↓
    → Transcode DASH legacy (sin cambios)
      → HLS / x265 fallback / iframe (sin cambios)
```

### Bugs encontrados y corregidos durante el testing
1. **Seeks dobles**: sin debounce, dos clicks rápidos lanzaban dos `_shakaLoad`
   concurrentes → colisión (error `O`). Fix: debounce 300ms + mutex `_tReloading`.
2. **Timeout 8s innecesario**: `waitForSegmentAt` chequeaba `video-{abs}.m4s` (absoluto)
   pero con `?t=X` el primer segmento es `video-1.m4s` (relativo). Fix: chequear
   `video-1.m4s` → segmento detectado en ~1s.
3. **Pantalla negra al seekear**: Shaka destruye y recrea → pantalla negra. Fix:
   freeze-frame (canvas drawImage del último cuadro) + spinner azul centrado.
4. **Panel superpuesto**: `v-else` en velocidad se emparejaba con el `v-if` de la fila
   de offset (no con el de Audio/Subs). Fix: `v-if="mode === 'speed'"` explícito.
