## Contexto: por qué se distorsionaba

Las LG viejas corren webOS antiguo con Chromium viejo. La UH8500 (2015-2016) = **webOS 3.0
= Chromium ~38**. La app usa CSS/JS modernos que Chromium 38 NO soporta:
- **JS**: arrow functions, clases, `import()` dinámico → no existen en Ch38.
- **CSS variables** (`var(--)`, 291 usos) → llegaron en Ch49. Ch38 descarta la declaración
  ENTERA (incluido el fallback inline) → todo sin estilo.
- **CSS Grid** (Ch57), **`gap`** flex (Ch84), **`aspect-ratio`** (Ch88), **`clamp()`/`min()`**
  (Ch79), **`backdrop-filter`** (Ch76), **`overflow:clip`** (Ch90), **`:focus-visible`** (Ch86).

**Concepto clave (cómo lo hace Netflix):** Netflix NO usa CSS/DOM en las TVs (motor propio
"Gibbon") + certifica dispositivos + da de baja lo muy viejo. Un indie no puede eso, pero SÍ
puede copiar la filosofía: **no pelear con el navegador viejo, hacer que el código "baje de
nivel" solo, y definir un piso**. No se apunta a "UH8500": se apunta a un PISO (Chromium 38)
y todo lo que esté por encima queda cubierto. Feature detection, no sniffing de modelo.

## Lo que se hizo — 3 pasos, cada uno verificado (type-check + 289 tests + build)

### Paso 1/3 — `d0d046e` — JavaScript (plugin-legacy)
- `@vitejs/plugin-legacy@8.1.0` + `terser` (compatibles con Vite 8, verificado antes de instalar).
- `vite.config.ts`: `legacy({ targets: ['chrome >= 38', 'safari >= 9', 'ios_saf >= 9', 'firefox >= 40'] })`.
- Genera un 2º bundle transpilado a ES5 + polyfills. El moderno usa `<script type=module>`;
  el viejo lo ignora y carga el legacy vía `nomodule` + SystemJS. **Solo afecta el build de
  producción**, no `netlify dev`. Verificado: 21 chunks legacy + polyfills generados.

### Paso 2/3 — `b255340` — Variables CSS (aplanado)
- `postcss.config.js` (nuevo) con `@csstools/postcss-global-data` (inyecta el `:root` de
  `src/style.css` en cada componente .vue, que Vite procesa por separado) +
  `postcss-custom-properties({ preserve: true })` (agrega el valor fijo ANTES de cada `var()`,
  conservando el `var()` para moderno). Aditivo: render idéntico en moderno.
- **Verificado seguro**: no hay theming dinámico (ningún `setProperty('--')`); los 34 tokens
  se definen una sola vez en `:root`. `var(--token)` era falsa alarma (solo en un comentario).

### Paso 3/3 — `4eaca8e` — Autoprefixer + fallbacks
- **3a (automático/aditivo)**: `autoprefixer` + `browserslist` (piso Ch38, en package.json) →
  prefijos `-webkit-`/`-moz-`. Fallbacks estáticos in-place: `clamp()` font-size → valor fijo;
  `min()` width → `width + max-width` (réplica EXACTA de min() con props que Ch38 soporta);
  `overflow:clip` → `overflow:hidden` previo. (El moderno usa la línea de abajo.)
- **3b — `src/legacy-compat.css` (nuevo, importado en main.ts)**: TODO dentro de
  `@supports not(...)` → el navegador moderno lo IGNORA por completo (imposible romperlo).
  * **Grid → Flexbox**: 5 carruseles horizontales (flex + flex-basis + margin) + 3 grillas 2D
    (flex-wrap). En Ch38 las declaraciones `display:grid` scoped se descartan por inválidas →
    sin conflicto de especificidad con estas reglas globales.
  * **aspect-ratio → truco `padding-bottom`** (2:3=150%, 16:9=56.25%) para contenedores de
    poster/backdrop que si no colapsan a alto 0. `.card-img` no se toca (es `<img>`, conserva
    ratio natural 2:3).
- **Verificado en el build**: moderno intacto (`display:grid` ×10 + `aspect-ratio` ×7 FUERA
  de @supports), y los fallbacks presentes DENTRO de @supports.

## 🛡️ Seguridad — decisión tomada
Audiencia = **personal/familiar**. Por eso:
- 🔴 **#1 Auth gate (password/PIN)** ~0.5 día — protege la cuenta RD (riesgo real: la app es
  pública y usa el RD PERSONAL del usuario → cualquiera lo quema / baneo / DMCA). Mismo patrón
  que RD_TOKEN: password en env var de Netlify, function valida y emite token, las Functions
  (`rd-token`/`rd-stream`/`rd-cleanup`/`subhash`) exigen ese token.
- 🟢 #2 Validación de URLs de streams (2-4 hrs, defensa en profundidad).
- ⬇️ Rate limiting y CSP → opcionales/después (con auth dejan de ser urgentes; CSP además es
  frágil, puede romper reproductores iframe / imágenes TMDB).
